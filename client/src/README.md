# كود الواجهة الأمامية المصدري (Client Source Code)

يحتوي هذا المجلد على الكود البرمجي الرئيسي لتطبيق الواجهة الأمامية المبني بـ React.

## هيكل الملفات والمجلدات:

- **`main.tsx`**: نقطة الانطلاق الرئيسية للتطبيق، حيث يتم تغليف التطبيق بـ `React.StrictMode` ومزود السياق `GameProvider`.
- **`App.tsx`**: موجه الشاشات الذكي ومحدد العرض بناءً على مرحلة اللعبة الحالية (`phase`) وحالة الانضمام للغرفة، بالإضافة إلى إدارة شريط الإشعارات العائمة.
- **`index.css`**: ملف التنسيقات الذي يحتوي على توجيهات Tailwind CSS وخطوط الواجهة العربية وقواعد التمرير.
- **`types/`**: تعريفات الأنواع والواجهات المشتركة.
- **`context/`**: سياق اللعبة وإدارة الحالة العامة والاتصال.
- **`hooks/`**: خطافات الصوتيات، الاهتزازات التفاعلية، ومقبس الـ WebSocket.
- **`components/`**: المكونات المشتركة وشاشات اللعبة السبع.
