# سياق إدارة حالة اللعبة (Game Context)

يحتوي هذا المجلد على كائن السياق المشترك (`GameContext`) لإدارة حالة اللعبة والاتصال المباشر.

## الملفات ومحتواها:

- **`GameContext.tsx`**:
  - يدير الحالة الشاملة للعبة واللاعب الحالي.
  - ينسق استقبال رسائل الـ WebSockets وتوزيعها وتحديث واجهات المستخدم.
  - يتولى حفظ واسترجاع بيانات الجلسة (`sessionToken` و `roomCode`) من التخزين المحلي لاستعادة الاتصال الفوري.
  - يوفر دوال تنفيذ العمليات (إنشاء غرفة، انضمام، تعديل ملف تعريفي، إرسال إجابة، تقديم خدعة، تصويت، وانتقال للجولات التالية).
