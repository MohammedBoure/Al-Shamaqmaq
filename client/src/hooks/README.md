# خطافات الواجهة (Client Custom Hooks)

يحتوي هذا المجلد على خطافات React المخصصة للتحكم بالصوتيات، الاهتزازات التفاعلية، والاتصال المباشر عبر الـ WebSockets.

## الملفات ومحتواها:

- **`useAudio.ts`**:
  - يولد جميع المؤثرات الصوتية للألعاب بواسطة `Web Audio API` دون الحاجة لأي ملفات صوتية خارجية.
  - يدعم نغمات النقر، المؤقت التنازلي التنبيهي، الإجابة الصحيحة، الخداع السري، التصويت، واحتفال الفوز، مع خيار كتم/تفعيل الصوت.
- **`useHaptic.ts`**:
  - تفعيل الاهتزازات التفاعلية (Haptic Feedback) على الهواتف الذكية لمختلف الأحداث (نقر، نجاح، تحذير، خطأ).
- **`useWebSocket.ts`**:
  - إدارة الاتصال المباشر بالخادم، إعادة الاتصال التلقائي عند انقطاع الشبكة، وإرسال نبضات `PING/PONG` للحفاظ على استقرار الجلسة.
