# المكونات المشتركة (Common Components)

يحتوي هذا المجلد على المكونات القابلة لإعادة الاستخدام في مختلف شاشات اللعبة.

## الملفات ومحتواها:

- **`TimerBar.tsx`**: شريط المؤقت الزمني التفاعلي الملون الذي يتغير مع تناقص الثواني مع نبضات تحذيرية حمراء عند اقتراب انتهاء الوقت.
- **`AvatarPicker.tsx`**: أداة اختيار وتغيير الشخصية الرمزية (Emoji Avatar) برسوم وحركات ارتدادية مرحة.
- **`AudioToggle.tsx`**: زر كتم وتفعيل المؤثرات الصوتية العامة للعبة.
- **`ConnectionBadge.tsx`**: شارة حالة الاتصال بالخادم المباشر (متصل / جارٍ الاتصال / منقطع).
- **`ConsolePet.tsx`**: كائن وشخصية الكونسول الكرتونية المتفاعلة (Console Pet) مع إمكانية تخصيص الألوان والأقنعة والنظارات والتعابير الحركية بنمط رسومي مطابق للشاشات الكرتونية (SVG).
- **`QRCodeView.tsx`**: مكون توليد وعرض رمز QR عالي الدقة لانضمام اللاعبين مباشرة للغرفة.
- **`CameraQRScanner.tsx`**: ماسح ضوئي لرموز QR يعمل مباشرة عبر كاميرا الهاتف/المتصفح مع رسوم ليزر تفاعلية وزر تحكم بالفلاش وتبديل الكاميرا.
- **`CategoryCard.tsx`**: بطاقة الفئة الآركيد المطابقة للتصميم ثلاثي الأبعاد مع الغلاف الفني وشارة الـ VIP وزر المعلومات وخط التحديد المتوهج.
- **`GameTopHeader.tsx`**: شريط الرأس العلوي التفاعلي للعبة المتضمن زر القائمة ☰، عداد الجولات والوقت المجنح، أيقونة المؤقت الدائري/الصحيح/التاج البارزة في المنتصف، وزر المشاركة.
