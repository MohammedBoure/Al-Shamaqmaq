# شاشات اللعبة (Game Screens)

يحتوي هذا المجلد على الشاشات الرئيسية الست المحددة في دورة اللعبة بالإضافة إلى شاشة التتويج النهائي:

## الملفات ومحتواها:

- **`LobbyScreen.tsx` (الشاشة 1)**:
  - شاشة الدخول وإنشاء أو الانضمام للغرفة برمزها مع ماسح الكاميرا الداخلي.
  - إدخال الاسم المستعار واختيار الأفاتار وضبط خيارات المضيف المتقدمة (المواضيع، عدد الجولات، وقت السؤال بالثواني، سعة اللاعبين، ونمط الفرق).
- **`WaitingRoomScreen.tsx` (الشاشة 2)**:
  - غرفة الانتظار المصممة بالثيم الكرتوني الأركيدي المطابق للصورة (`image_20261007_150132.png`).
  - دعم وضع الفرق التنافسي (الفريق الأحمر 🔴 ضد الفريق الأزرق 🔵) مع إمكانية تبديل الفريق وموازنة اللاعبين تلقائياً.
  - إعدادات تفاعلية فورية لتحديد الوقت لكل جولة (عدد الثواني المسموح بها لكل سؤال)، الحد الأقصى للاعبين بالأرقام مباشرة، وعدد الجولات الإجمالي.
  - بطاقة المشاركة القابلة للطي مع توليد رمز QR ديناميكي، زر مشاركة الرابط عبر Web Share API، زر إملاء ونطق الرمز صوتياً باللغة العربية، وماسح الكاميرا الداخلي.
  - زر وقسم الفئات المباشر لفتح متصفح الفئات الآركيد.
- **`CategoryBrowserScreen.tsx` (شاشة متصفح الفئات الآركيد)**:
  - واجهة الفئات المطابقة تماماً لتصميم المرجع (`image_20261007_150613.png`).
  - شريط العنوان البنفسجي المجنح "الفئات" مع البطاقات الثلاث التفاعلية.
  - صندوق التحكم والبحث (تصفية، نرد عشوائي 🎲، اختيار الكل ✔، وحقل بحث فوري).
  - أقسام الفئات القابلة للطي بنمط أكورديون وشارات سداسية وأيقونات ملونة (فئات الأسبوع، فئات جديدة، منوعات، علوم).
  - شبكة بطاقات تفاعلية رباعية الأعمدة بأغلفة فنية متجهة وشارات VIP، وأزرار معلومات منبثقة، وشريط تحديد أخضر مشع.
  - شريط سفلي متزامن بالعداد "XX فئات • YY لاعبين" وزر "ابدأ اللعبة" وتبويبات لعبة/دردشة.
- **`TopicSelectionScreen.tsx` (الشاشة 3)**:
  - شاشة اختيار الموضوع وتدوير الدور بين اللاعبين مع شبكة البطاقات الآركيد والمؤقت الزمني.
- **`AnsweringScreen.tsx` (الشاشة 4)**:
  - مطابقة للصورة المرجعية (`image_20261007_150906.png`).
  - شريط الرأس العلوي المجنح مع المؤقت الدائري ذي الفتحات الزرقاء `1/10 [المؤقت] 0:50`.
  - بطاقة السؤال البنفسجية بنمط النقاط الدائرية وشارة الفئة العلوية وكبسولة التفاعل `[ 👍 | 👎 ]`.
  - كائن شخصية اللاعب في المنتصف مع شارة النقاط في الأعلى والاسم بالأسفل.
  - صندوق الإدخال الأزرق السفلي مع حقل الإدخال الأبيض العريض وزر "أجب" الرمادي ثلاثي الأبعاد وكبسولة التبديل (لعبة / دردشة).
- **`VotingScreen.tsx` (الشاشة 5)**:
  - مطابقة للصورة المرجعية (`image_20261007_150943.png`).
  - اللسان العلوي الشبه منحرف "اختر إجابة" فوق الحاوية الزرقاء.
  - شبكة خيارات الإجابات مع تعطيل إجابة اللاعب الذاتية وتثبيت شارة سوداء "إجابتك" عليها لمنع التصويت للذات.
- **`RoundResultsScreen.tsx` (الشاشة 6)**:
  - مطابقة للصورتين المرجعيتين (`image_20261007_151028.png` و `image_20261007_151046.png`).
  - مرحلة كشف الإجابة (Reveal): البطاقة الذهبية المتوهجة مع لسان "الإجابة هي"، صورة شخصية صاحب الإجابة الصحيحة في الأعلى، كشف الخدع بالأسفل، وزر "أظهر النتيجة".
  - مرحلة لوحة النتائج (Leaderboard): النجوم الثلاث الذهبية ⭐⭐⭐، صفوف اللاعبين الصفراء بنسب أشرطة التقدم المخططة وزيادات النقاط `+X`، وزر "المتابعة" الأزرق ثلاثي الأبعاد.
- **`CharacterSelectScreen.tsx` (شاشة تخصيص شخصية اللاعب)**:
  - مطابقة تماماً لواجهة التصميم المرجعية (`image_20261007_145937.png`):
  - صندوق الكونسول الأخضر/التركوازي مع شاشة الأشعة الزرقاء (Sunburst Screen) التي تعرض شخصية الكونسول الكرتونية.
  - حقل إدخال الاسم المباشر ("أدخل اسمك").
  - درج التخصيص السفلي الأزرق مع التبويبات الثلاثة (الألوان، الأقنعة، النظارات) وزر الإعادة وزر "المتابعة" الأزرق ثلاثي الأبعاد.
- **`GameOverScreen.tsx` (الشاشة 7)**:
  - منصة التتويج النهائي (Podium) الثلاثية، إطلاق الألعاب النارية والـ Confetti، وتتويج بطل اللعبة أو الفريق الفائز في وضع الفرق مع إمكانية بدء جولة جديدة.
