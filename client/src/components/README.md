# مكونات الواجهة (Frontend Components)

يحتوي هذا المجلد على مكونات واجهة المستخدم مقسمة إلى:

- **`common/`**: المكونات المشتركة المعاد استخدامها مثل شريط المؤقت، لاقط الأفاتار، زر الصوت، وشارة الاتصال.
- **`screens/`**: شاشات اللعبة الكاملة (Lobby, WaitingRoom, TopicSelection, Answering, Voting, RoundResults, GameOver).
