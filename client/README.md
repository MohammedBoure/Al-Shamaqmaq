# واجهة اللعبة الأمامية (Frontend Client)

مشروع واجهة المستخدم التفاعلية (Frontend) المبني باستخدام **React 18** و **TypeScript** و **Tailwind CSS** و **Vite**.

## هيكل الملفات والمجلدات:

- **`index.html`**: الصفحة الرئيسية الموجهة بالكامل للغة العربية (RTL) مع خطوط `Readex Pro` و `Cairo` وإعدادات الهاتف والـ PWA.
- **`package.json`**: حزم الواجهة الأمامية والأدوات.
- **`tsconfig.json`**: إعدادات TypeScript للواجهة.
- **`vite.config.ts`**: إعدادات خادم التطوير وتوجيه وكيل الـ API و WebSocket.
- **`tailwind.config.js`**: لوحة الألوان الحيوية بأسلوب الألعاب (Arcade Theme) والمؤثرات النيونية والظلال والأنيميشن.
- **`postcss.config.js`**: معالج التنسيقات لـ Tailwind.
- **`src/`**: الكود المصدري للواجهة والمكونات والحالات والشاشات.
- **`src/components/common/ThemeToggle.tsx`**: زر التبديل الفوري بين المظهر الأبيض الخفيف (White & Light Arcade Mode) والمظهر الداكن (Dark Arcade Mode).

## مزايا التجاوب (Responsive & Adaptive):
- **الهواتف الذكية (Mobile-First):** عناصر لمس عريضة ومريحة للإبهام، مؤقتات دائرية، بدون أي تمرير أفقي، مع دعم الاهتزازات التفاعلية (Haptics).
- **أجهزة الكمبيوتر والشاشات العريضة (Desktop & PC):** تقسيم شبكي متعدد الأعمدة (Multi-column Grids)، واجهات عريضة مريحة للعين، واختصارات لوحة المفاتيح الفورية (Enter للإجابة، ومفاتيح الأرقام).
