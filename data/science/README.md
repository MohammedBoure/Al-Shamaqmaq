# مجلد فئة العلوم (data/science)

يحتوي هذا المجلد على المواضيع والألغاز والأسئلة الخاصة بفئة "علوم" في اللعبة.

## الملفات المتاحة:

- **`category.json`**: بيانات تعريف الفئة الرئيسية (العنوان، الأيقونة، الشارة، واللون).
- **`astronomy_space.json`**: موضوع الفلك والفضاء وأسرار الكواكب والنجوم والمجرات.
- **`general_science.json`**: موضوع العلوم العامة والتجارب المعملية والحقائق الطبيعية.
- **`physics.json`**: موضوع الفيزياء وقوانين الحركة والطاقة والجسيمات.
- **`animals.json`**: موضوع عالم الحيوان وسلوكيات الكائنات وعجائب الحياة البرية.
- **`biology.json`**: موضوع علم الأحياء والخلايا والوراثة (VIP).
- **`mathematics.json`**: موضوع الرياضيات والجبر والأرقام والمنطق (VIP).
- **`botany.json`**: موضوع علم النبات والغابات والأشجار والزهور (VIP).
- **`anatomy_health.json`**: موضوع علم الجسم والصحة وتشريح الأعضاء (VIP).
- **`medicine.json`**: موضوع الطب العام وتاريخ الأدوية والعلاجات (VIP).
- **`engineering.json`**: موضوع الهندسة والعمارة والمباني والجسور (VIP).
- **`medical_terms.json`**: موضوع المصطلحات الطبية الشائعة وجذورها (VIP).
- **`math_puzzles.json`**: موضوع ألغاز الرياضيات والمسائل الحسابية الذكية (VIP).
- **`psychology.json`**: موضوع علم النفس وخفايا العقل البشري والسلوكيات.
