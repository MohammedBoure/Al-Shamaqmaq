# مجلد الفئات الجديدة (data/new_categories)

يحتوي هذا المجلد على المواضيع والألغاز الحديثة المضافة حديثاً للعبة.

## الملفات المتاحة:

- **`category.json`**: بيانات تعريف فئة الفئات الجديدة (العنوان، الأيقونة، الشارة، واللون).
- **`ai_tech.json`**: موضوع الذكاء الاصطناعي والتقنية والابتكارات الرقمية الحديثة.
- **`video_games.json`**: موضوع ألعاب الفيديو وجيمينج وأشهر المنصات والشخصيات.
