# مجلد فئة المنوعات (data/variety)

يحتوي هذا المجلد على مواضيع وألغاز فئة "منوعات" في اللعبة.

## الملفات المتاحة:

- **`category.json`**: بيانات تعريف فئة المنوعات (العنوان، الأيقونة، الشارة، واللون).
- **`islamic_history.json`**: موضوع تاريخ وحضارة إسلامية وأسئلة العصور الإسلامية والمعالم.
- **`arabic_literature.json`**: موضوع لغة عربية وأدب وشعر ومعاني الكلمات.
- **`world_geography.json`**: موضوع جغرافيا وعجائب العالم وعواصم وتضاريس.
- **`inventions.json`**: موضوع اختراعات واكتشافات مذهلة غيرت مسار التاريخ.
- **`riddles.json`**: موضوع ألغاز وفوازير شعبية وتراثية ممتعة.
