# مجلد فئات الأسبوع (data/weekly)

يحتوي هذا المجلد على المواضيع المتجددة أسبوعياً في اللعبة.

## الملفات المتاحة:

- **`category.json`**: بيانات تعريف فئة الأسبوع (العنوان، الأيقونة، الشارة، واللون).
- **`weekly_celebrities.json`**: موضوع مشاهير وترند وأشهر الشخصيات الحالية.
- **`weekly_sports.json`**: موضوع رياضة وأبطال وكؤوس العالم والأرقام القياسية.
