# اختبارات النظام (Automated Test Suite)

يحتوي هذا المجلد على الاختبارات الشاملة (Unit & Integration Tests) للتحقق من سلامة منطق اللعبة وواجهات الـ REST والـ WebSockets.

## الملفات ومحتواها:

- **`normalizer.test.ts`**:
  - اختبارات دوال تطبيع النصوص العربية وإزالة التشكيل والتطويل.
  - اختبارات أنماط المطابقة (`text_exact`, `text_normalized`, `number`).
  - اختبارات كشف الإجابات المزيفة المكررة لمنع تشتيت اللعبة.
- **`topicService.test.ts`**:
  - اختبارات تحميل ملف الأسئلة والتأكد من عدم تسريب الإجابات في ملخصات المواضيع.
  - اختبارات اختيار الألغاز العشوائية وضمان عدم تكرارها داخل نفس الغرفة.
- **`roomStateMachine.test.ts`**:
  - اختبار شامل وتكاملي لدورة اللعبة الكاملة (Core Game Loop):
    1. انضمام اللاعبين وتعديل الأسماء وحفظها.
    2. بدء الجولة وتدوير دور اختيار الموضوع.
    3. مرحلة الإجابة والخداع، وكشف الإجابة الصحيحة سراً وطلب إجابة مزيفة.
    4. منع إدخال الإجابة الصحيحة كإجابة مزيفة، ومنع الإجابات المكررة.
    5. مرحلة التصويت، خلط الخيارات، ومنع التصويت للإجابة الذاتية.
    6. احتساب وتوزيع النقاط بدقة وتحديث لوحة الصدارة.
- **`api.test.ts`**:
  - اختبار مسارات الـ REST API (`/api/health`, `/api/topics`, `/api/rooms`).
- **`websocket.test.ts`**:
  - اختبار اتصالات الـ WebSockets وتزامن الأحداث المباشرة.
  - اختبار آلية إعادة الاتصال السلسة (Reconnect) باستخدام `sessionToken`.
- **`roomSettingsAndTeams.test.ts`**:
  - اختبارات تعيين وقت الجولة وعدد الجولات والحد الأقصى للاعبين بالأرقام المباشرة.
  - اختبارات وضع الفرق (Team Mode: الأحمر ضد الأزرق)، الموازنة التلقائية، وحساب نتائج الفرق.
