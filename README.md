# خادم لعبة الألغاز والخداع الاجتماعي (Deception Puzzle Game Backend)

واجهة خلفية متكاملة وقوية (Backend) مبنية بتقنيات **Node.js** و **TypeScript** و **WebSockets** و **Express** لإدارة لعبة جماعية قائمة على الألغاز والتضليل والمنافسة الاجتماعية اللحظية في الوقت الفعلي (على غرار نمط ألعاب Jackbox / Fibbage).

---

## 🌟 مميزات النظام

1. **محرك حالات لحظي (Real-time State Machine):**
   - إدارة كاملة لدورة اللعبة عبر بروتوكول WebSockets مع تزامن دقيق لكل المراحل:
     - `LOBBY`: انتظار اللاعبين، تخصيص الأسماء والأفاتار، وضبط إعدادات الغرفة.
     - `TOPIC_SELECTION`: تدوير دور اختيار الموضوع بين اللاعبين مع مؤقت زمني واختيار تلقائي عند انتهاء الوقت.
     - `ANSWERING`: استقبال الإجابات النصية الحرة، والتحقق الذكي، وصياغة الخداع.
     - `VOTING`: عرض الإجابة الحقيقية والإجابات المزيفة عشوائياً وبسرية، مع منع التصويت الذاتي.
     - `ROUND_RESULTS`: احتساب دقيق للنقاط وتوزيعها وكشف هوية أصحاب الإجابات والمصوتين.
     - `GAME_OVER`: إعلان الترتيب النهائي وتتويج الفائز.

2. **خوارزمية ذكية لمطابقة النصوص العربية (Smart Text Matching):**
   - إزالة وتجاهل علامات التشكيل والحركات (فتحة، ضمة، كسرة، تنوين، شدة، سكون).
   - إزالة التطويل (الكشيدة).
   - توحيد الهمزات والألف (`أ`, `إ`, `آ`, `ٱ` إلى `ا`).
   - توحيد الياء والألف المقصورة (`ى` إلى `ي`).
   - توحيد التاء المربوطة والهاء (`ة` إلى `ه`).
   - تحويل الأرقام المشرقية والفارسية (`٠-٩`) إلى الأرقام القياسية (`0-9`).
   - دعم المقارنة التسامحية وخوارزمية مسافة ليفنشتاين (Levenshtein Distance) للأخطاء المطبعية الطفيفة وتجاوز "ال" التعريف.
   - دعم أنواع الإجابات: `text_exact`, `text_normalized`, `number`.

3. **آلية الخداع ومنع التكرار (Deception & Deduplication):**
   - عند إجابة اللاعب إجابة صحيحة، يخطره السيرفر سراً ويطلب منه فوراً تقديم "إجابة مزيفة مقنعة" (Bluff).
   - إذا حاول تقديم الإجابة الصحيحة كإجابة مزيفة، يرفضها السيرفر ويطلب منه إدخال خدعة خاطئة.
   - إذا كتب إجابة خاطئة، تُعتمد تلقائياً كإجابته المضللة.
   - كشف التشابه بين إجابات اللاعبين ومطالبتهم الفورية بإعادة الصياغة لتجنب الإجابات المكررة.

4. **نظام النقاط الدقيق (Scoring):**
   - **+1 نقطة** للاعب الذي يصوت للإجابة الأصلية الصحيحة.
   - **+1 نقطة** لصاحب أي إجابة مزيفة عن كل لاعب ينخدع ويصوت لإجابته المضللة.

5. **فصل المحتوى بالكامل في ملفات JSON:**
   - ملف `data/topics.json` مهيكل ونظيف بالكامل دون أي شفرات برمجية، مما يتيح لأي مشرف أو صانع محتوى إضافة أو تعديل الأسئلة والألغاز بسهولة.
   - خلو كامل من التلميحات (Hints) وفق المتطلبات.

6. **إعادة الاتصال السلس وحفظ الهوية (Seamless Reconnection):**
   - توليد `sessionToken` فريد لكل لاعب.
   - عند انقطاع اتصال الهاتف أو الإنترنت، يمكن للاعب العودة فوراً واستعادة مقعده ونقاطه وسياق المرحلة الحالية تلقائياً.

## 🚀 التثبيت والتشغيل

### المتطلبات المسبقة:
- Node.js (الإصدار 18 فما فوق، يفضل الإصدار 20+ أو 24 LTS).
- npm (الإصدار 9 فما فوق).

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تشغيل بيئة التطوير المباشرة:
```bash
npm run dev
```

### 3. بناء المشروع وتشغيل نسخة الإنتاج:
```bash
npm run build
npm start
```

### 4. تشغيل حزمة الاختبارات الآلية:
```bash
npm test
```

## 📡 واجهات الـ REST API

| الطريقة | المسار | الوصف |
|---------|--------|-------|
| `GET` | `/api/health` | فحص جاهزية ونشاط السيرفر. |
| `GET` | `/api/topics` | استعراض قائمة المواضيع المتاحة وأوصافها وعدد الأسئلة (دون كشف الإجابات). |
| `POST` | `/api/rooms` | إنشاء غرفة جديدة من قبل المضيف مع تحديد المواضيع المسموح بها. |
| `GET` | `/api/rooms/:roomCode` | فحص حالة الغرفة والمرحلة الحالية وقائمة اللاعبين. |

### مثال طلب إنشاء غرفة:
```json
POST /api/rooms
Content-Type: application/json

{
  "hostNickname": "فارس الألغاز",
  "hostAvatar": "🦁",
  "allowedTopicIds": ["islamic_history", "science_nature"]
}
```

## 🔌 بروتوكول الـ WebSockets (`/ws`)

الاتصال متاح عبر: `ws://localhost:3000/ws`

### رسائل العميل (Client to Server):
- `JOIN_ROOM`: للانضمام لغرفة بكود الغرفة أو عبر `sessionToken` لإعادة الاتصال:
  ```json
  { "type": "JOIN_ROOM", "payload": { "roomCode": "A3KZ", "nickname": "سارة", "avatar": "🦊" } }
  ```
- `UPDATE_PROFILE`: لتعديل الاسم أو الشخصية الرمزية وحفظها:
  ```json
  { "type": "UPDATE_PROFILE", "payload": { "nickname": "سارة الذكية", "avatar": "⭐" } }
  ```
- `UPDATE_SETTINGS`: لتعديل إعدادات الغرفة (المضيف فقط في مرحلة الانتظار):
  ```json
  { "type": "UPDATE_SETTINGS", "payload": { "allowedTopicIds": ["science_nature"], "totalRounds": 5 } }
  ```
- `START_GAME`: لبدء اللعبة من قبل المضيف:
  ```json
  { "type": "START_GAME" }
  ```
- `SELECT_TOPIC`: لاختيار موضوع الجولة (من قبل اللاعب صاحب الدور):
  ```json
  { "type": "SELECT_TOPIC", "payload": { "topicId": "science_nature" } }
  ```
- `SUBMIT_ANSWER`: لتقديم الإجابة النصية الحرة:
  ```json
  { "type": "SUBMIT_ANSWER", "payload": { "answer": "القلب" } }
  ```
- `SUBMIT_BLUFF`: لتقديم إجابة مزيفة مقنعة (لمن أجاب صحيحاً):
  ```json
  { "type": "SUBMIT_BLUFF", "payload": { "bluff": "المعدة والأمعاء" } }
  ```
- `SUBMIT_VOTE`: لاختيار الإجابة التي يعتقد اللاعب أنها حقيقية (محظور على اللاعب اختيار إجابته الذاتية):
  ```json
  { "type": "SUBMIT_VOTE", "payload": { "optionId": "option-uuid" } }
  ```
- `NEXT_ROUND`: لتخطي شاشة النتائج والانتقال للجولة التالية مبكراً (من قبل المضيف).
- `PING`: لفحص زمن الاستجابة ونبض الاتصال (يرد بـ `PONG`).

### رسائل السيرفر (Server to Client):
- `ROOM_JOINED`: تأكيد الانضمام وتزويد اللاعب ببيانات الغرفة ورمزه السري `sessionToken`.
- `TOPIC_SELECTION_STARTED`: إعلان بدء مرحلة اختيار الموضوع واللاعب صاحب الدور.
- `ROUND_STARTED`: عرض نص اللغز وصورته وبدء عداد وقت الإجابة.
- `ANSWER_FEEDBACK`: إشعار فوري للاعب بنتيجة إجابته (إذا كانت صحيحة يُطلب منه كتابة خدعة سراً، وإذا كانت خاطئة تُعتمد تلقائياً).
- `BLUFF_REQUESTED`: شاشة خاصة للمتسابق الذكي لكتابة الخدعة.
- `VOTING_STARTED`: عرض جميع الخيارات مجهولة المصدر ومرتبة عشوائياً.
- `ROUND_RESULTS_ANNOUNCED`: كشف الخيارات الصحيحة، وهوية أصحاب الخدع، وتوزيع النقاط، وتحديث لوحة الصدارة.
- `GAME_OVER_ANNOUNCED`: إعلان الفائز النهائي بعد انتهاء الجولات.
- `TIMER_TICK`: بث مستمر للثواني المتبقية لمزامنة شريط الوقت في واجهات المستخدم.
- `ERROR`: إرسال كود الخطأ ورسالة توضيحية بالعربية.
