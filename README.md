# لعبة الألغاز والخداع الاجتماعي (Deception Puzzle Game) - Full Stack

نظام ولعبة ألغاز وخداع اجتماعي متكاملة (Backend + Frontend) قائمة على المنافسة الجماعية اللحظية في الوقت الفعلي (شبيهة بأسلوب Jackbox Party / Fibbage / Kahoot).

---

## 🌟 مميزات النظام وتجربة المستخدم (Features & UX)

### 🎨 الواجهة الأمامية (Frontend):
1. **دعم كامل ومثالي للغة العربية (RTL First):**
   - واجهة كاملة بالاتجاه العربي (RTL) مع خطوط عصرية واضحة ومقروءة (`Readex Pro` و `Cairo`).
2. **تصميم Mobile-First بالكامل:**
   - محسنة تماماً لشاشات الهواتف المحمولة وتعمل كتطبيق ويب تقدمي (PWA) بدون أي تمرير أفقي أو فراغات ميتة، مع أزرار كبيرة سهلة اللمس بإبهام اليد (Thumb-friendly touch targets).
3. **ثيم الألعاب النيوني (Arcade / Gaming Theme):**
   - تصميم داكن عصري بتباين لوني جذاب (ألوان نيون: البنفسجي، الوردي السايبر، التركواز الفاقع، الأصفر الكهربائي، والأخضر الزمردي).
   - تأثيرات حركية خفيفة (Micro-interactions) وظلال متوهجة عند النقر والتفاعل.
4. **مؤثرات صوتية واهتزازات تفاعلية (Audio & Haptics):**
   - توليد جميع المؤثرات الصوتية للألعاب ديناميكياً عبر `Web Audio API` (نغمات النقر، صفارات المؤقت التنازلي التنبيهية، نغمة الإجابة الصحيحة السرية، ونغمة احتفال الفوز) دون الحاجة لملفات صوتية خارجية.
   - دعم الاهتزازات التفاعلية (Haptic feedback عبر `navigator.vibrate`) لأجهزة الهواتف الذكية.
   - إطلاق ألعاب نارية و Confetti احتفالية عند كشف النتائج والتتويج.
5. **شاشات اللعبة السبع:**
   - **الشاشة 1: شاشة الدخول وإنشاء/الانضمام للغرفة (Lobby Setup):** تبديل سلس بين إنشاء وانضمام، إدخال الاسم، لاقط الأفاتار التفاعلي، وإعدادات الجولات للمضيف.
   - **الشاشة 2: غرفة الانتظار (Waiting Room):** عرض كود الغرفة بخط ضخم مع نسخ ومشاركة، شبكة اللاعبين المنضمين المباشرة، وزر بدء المسابقة للمضيف.
   - **الشاشة 3: اختيار الموضوع (Theme Selection):** بطاقات المواضيع المرئية مع إظهار اللاعب صاحب الدور والعداد التنازلي.
   - **الشاشة 4: شاشة السؤال والإجابة الحرة (Puzzle & Deception Phase):** عرض نص اللغز وصورته، شريط المؤقت المتغير لونه، حقل الإجابة الحرة، والبطاقة السرية لمن أجاب صحيحاً لصياغة خدعة كاذبة ومقنعة.
   - **الشاشة 5: شاشة التصويت (Voting Arena):** بطاقات الخيارات الملونة عشوائياً، مع تعطيل إجابة اللاعب الذاتية وحظر تصويته لها.
   - **الشاشة 6: شاشة كشف النتائج وتوزيع النقاط (The Reveal & Round Recap):** كشف درامي مبهج مع Confetti، توضيح الإجابة الصحيحة وأصحاب الخدع واللاعبين المخدوعين، ولوحة الصدارة الحية.
   - **الشاشة 7: شاشة نهاية اللعبة والتتويج (Game Over & Podium):** منصة تتويج أصحاب المراتب الثلاث الأولى مع كؤوس وميداليات وإمكانية بدء جولة جديدة.

---

### ⚙️ الواجهة الخلفية (Backend):
1. **محرك حالات لحظي (Real-time State Machine عبر WebSockets):**
   - إدارة كاملة لدورة اللعبة بدقة: `LOBBY` $\rightarrow$ `TOPIC_SELECTION` $\rightarrow$ `ANSWERING` $\rightarrow$ `VOTING` $\rightarrow$ `ROUND_RESULTS` $\rightarrow$ `GAME_OVER`.
   - إدارة المؤقتات التنازلية اللحظية بالثواني مع بث مباشر لجميع اللاعبين.
2. **خوارزمية ذكية لمطابقة النصوص العربية (Smart Arabic Matching):**
   - إزالة وتجاهل علامات التشكيل والحركات، التنوين، الشدة، والسكون، والكشيدة.
   - توحيد الهمزات والألف، الياء والألف المقصورة، والتاء المربوطة والهاء.
   - تحويل الأرقام المشرقية والفارسية إلى أرقام قياسية.
   - المقارنة التسامحية وخوارزمية Levenshtein للأخطاء المطبعية الطفيفة وتجاوز "ال" التعريف.
   - كشف الإجابات المزيفة المكررة لمنع التكرار وتوجيه اللاعب لتنويع خدعته فوراً.
3. **نظام النقاط الدقيق (Scoring):**
   - **+1 نقطة** لمن يصوت للإجابة الصحيحة الأصلية.
   - **+1 نقطة** لصاحب أي إجابة مزيفة عن كل لاعب ينخدع ويصوت لإجابته المضللة.
4. **استعادة الجلسة وإعادة الاتصال السلس (Seamless Reconnect):**
   - تتبع اللاعبين برمز جلسة فريد `sessionToken`؛ عند انقطاع الاتصال يعود اللاعب فوراً لمقعده ونقاطه وسياق مرحلته الجارية.
5. **بنك الأسئلة المهيكل في ملفات JSON:**
   - ملف `data/topics.json` مهيكل ونظيف بالكامل دون أي شفرات برمجية، وخالٍ تماماً من التلميحات (Hints).

```
game/

├── src/                        # كود السيرفر الخلفي (Backend)
│   ├── config/                 # إعدادات النظام والمؤقتات
│   ├── controllers/            # متحكمات REST و WebSocket

│   ├── index.ts                # نقطة تشغيل السيرفر
│   └── README.md
├── client/                     # كود الواجهة الأمامية (Frontend - React + Tailwind)
│   ├── index.html              # صفحة HTML الرئيسية للواجهة

│   ├── src/
│   │   ├── components/
│   │   │   ├── common/         # شريط المؤقت، لاقط الأفاتار، زر الصوت، شارة الاتصال
│   │   │   └── screens/        # الشاشات السبع الرئيسية
│   │   ├── context/            # سياق إدارة اللعبة والاتصال (GameContext)
│   │   ├── hooks/              # خطافات الصوت، الاهتزاز، والـ WebSocket
│   │   ├── types/              # تعريفات الأنواع للواجهة
│   │   ├── App.tsx             # موجه الشاشات الذكي
```

## 🚀 التثبيت والتشغيل السريع

### 1. تثبيت الحزم للواجهتين:
```bash
# تثبيت حزم الباك إند
npm install

# تثبيت حزم الواجهة الأمامية
npm --prefix client install
```

### 2. تشغيل بيئة التطوير المباشرة:
في نافذتي طرفية:
```bash
# الطرفية 1: تشغيل السيرفر الخلفي (منفذ 3000)
npm run dev

# الطرفية 2: تشغيل خادم الواجهة الأمامية (منفذ 5173)
npm run client:dev
```
افتح المتصفح على: `http://localhost:5173`

### 3. بناء المشروع وتشغيله كحزمة واحدة للإنتاج:
```bash
# بناء الباك إند والواجهة معاً
npm run build:all

# تشغيل الخادم الموحد
npm start
```
سيعمل الخادم الموحد على: `http://localhost:3000` ليخدم واجهات الـ REST والـ WebSockets وصفحات الـ Frontend في وقت واحد!

### 4. تشغيل حزمة الاختبارات الآلية:
```bash
npm test
```
