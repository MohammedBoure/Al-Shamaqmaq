# تعريفات الأنواع (TypeScript Types)

يحتوي هذا المجلد على جميع تعريفات الأنواع والواجهات (Interfaces & Types) المستخدمة عبر طبقات الـ Backend والـ WebSocket.

## الملفات ومحتواها:

- **`topics.ts`**:
  - `Puzzle`: بنية اللغز (معرّف، نص السؤال، رابط الصورة، نوع الإجابة، الإجابات الصحيحة المقبولة).
  - `Topic`: بنية الموضوع وقائمته من الألغاز.
  - `TopicSummary`: ملخص الموضوع المعروض للعملاء دون كشف الألغاز.
  - `PublicPuzzle`: اللغز المرسل للعميل أثناء الجولة دون الإجابات الصحيحة.
- **`game.ts`**:
  - `GamePhase`: حالات اللعبة (`LOBBY`, `TOPIC_SELECTION`, `ANSWERING`, `VOTING`, `ROUND_RESULTS`, `GAME_OVER`).
  - `PlayerProfile`: الملف التعريفي للاعب، وحالة الاتصال والنقاط.
  - `PlayerAnswerState`: حالة إجابة وخداع اللاعب أثناء الجولة.
  - `VotingOption` و `PublicVotingOption`: خيارات التصويت المعروضة للاعبين.
  - `RoundResult`: تفاصيل نتيجة الجولة، وتوزيع النقاط واللاعبين المخدوعين.
  - `RoomSettings`: إعدادات أوقات الجولات والمواضيع المسموحة.
- **`messages.ts`**:
  - الأحداث والرسائل المتبادلة عبر الـ WebSocket بين العميل والسيرفر (Client-to-Server و Server-to-Client) مع حمولاتها (Payloads).
- **`index.ts`**:
  - نقطة تصدير موحدة لجميع الأنواع لتسهيل استيرادها في باقي أجزاء النظام.
