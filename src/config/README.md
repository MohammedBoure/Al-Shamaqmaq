# إعدادات النظام (Application Configuration)

يحتوي هذا المجلد على إعدادات السيرفر واللعبة والبيئة التشغيلية.

## الملفات ومحتواها:

- **`index.ts`**:
  - يحتوي على كائن `config` والواجهة `AppConfig`.
  - يحدد المنافذ الافتراضية، المؤقتات الزمنية لكل مرحلة (اختيار الموضوع، كتابة الإجابة، صياغة الإجابة المزيفة، التصويت، كشف النتائج).
  - يحدد الحدود الدنيا والقصوى لعدد اللاعبين والجولات وفترات مهلة انقطاع الاتصال وإعادة الاتصال.
