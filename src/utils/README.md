# الأدوات المساعدة (Utilities)

يحتوي هذا المجلد على دوال وخوارزميات مساعدة لمعالجة النصوص وتوليد الرموز العشوائية.

## الملفات ومحتواها:

- **`textNormalizer.ts`**:
  - خوارزمية ذكية لمطابقة وتطبيع النصوص العربية والإنجليزية.
  - إزالة التشكيل والتطويل وتوحيد الحروف المتقاربة (الهمزات، التاء المربوطة والهاء، الياء والألف المقصورة).
  - تحويل الأرقام المشرقية والفارسية إلى أرقام قياسية موحدة.
  - خوارزمية Levenshtein Distance لاحتساب الفروقات المطبعية الطفيفة.
  - دعم أنماط التحقق: `text_exact`, `text_normalized`, `number`.
  - كشف الإجابات المزيفة المكررة لمنع التكرار بين اللاعبين.
- **`codeGenerator.ts`**:
  - توليد رموز الغرف السهلة للقراءة والمشاركة (تجنب الحروف المتشابهة مثل O و 0 و I و 1).
  - توليد رموز الجلسات (Session Tokens) ومعرفات الـ UUID الآمنة تزامناً مع متطلبات إعادة الاتصال.
