# كود الواجهة الخلفية (Backend Source Code)

يحتوي هذا المجلد على الكود المصدري الكامل للنظام مقسماً بشكل وحداتي منظم (Modular Architecture).

## هيكل المجلدات والملفات:

- **`config/`**: إعدادات السيرفر والمؤقتات الزمنية للجولات وقيم البيئة التشغيلية.
- **`types/`**: جميع تعريفات الأنواع والواجهات (TypeScript Interfaces & Types) للغرف واللاعبين والأسئلة وحزم بيانات الـ WebSocket والـ REST API.
- **`utils/`**: دوال مساعدة لمعالجة وتطبيع النصوص العربية وخوارزميات فحص التطابق وكشف التكرار وتوليد أكواد الغرف والجلسات.
- **`models/`**: نماذج الكائنات الرئيسية (`Player` و `Room`) ومحرك الحالات المباشر (State Machine) لجميع مراحل اللعبة.
- **`services/`**: طبقة الخدمات المستقلة لإدارة المواضيع والأسئلة (`TopicService`) وإدارة الغرف والجلسات والتنظيف الدوري (`RoomManager`).
- **`controllers/`**: معالجات واجهات الـ REST API ومتحكم اتصالات الـ WebSockets في الوقت الفعلي.
- **`server.ts`**: دالة إنشاء وتجميع تطبيق Express وخادم WebSockets المشترك وتهيئة المسارات.
- **`index.ts`**: نقطة الانطلاق الأساسية للتشغيل (Entry point) والتعامل مع إشارات الإيقاف النظيف.
