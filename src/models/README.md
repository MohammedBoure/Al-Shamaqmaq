# نماذج اللعبة (Game Models)

يحتوي هذا المجلد على النماذج الأساسية للعبة وإدارة الكائنات وحالاتها.

## الملفات ومحتواها:

- **`Player.ts`**:
  - نموذج اللاعب (`Player`): يحفظ بيانات الهوية (المعرف، الاسم المستعار، الأفاتار/الإيموجي)، رمز الجلسة (Session Token)، نقاط الجولة والنقاط الإجمالية، حالة الاتصال ومقبس الـ WebSocket.
  - يدير حالات إجابة اللاعب وخداعه وتصويته وإعادة ضبطها مع كل جولة.
  - يوفر دالة إرسال الرسائل الفردية المشفرة بصيغة JSON.
- **`Room.ts`**:
  - نموذج الغرفة ومحرك الحالة المباشر (`State Machine`):
    1. **مرحلة الانتظار (`LOBBY`):** انضمام اللاعبين، تغيير الأسماء والأفاتار، ضبط الإعدادات.
    2. **مرحلة اختيار الموضوع (`TOPIC_SELECTION`):** تدوير دور اختيار الموضوع بين اللاعبين دورة تلو دورة.
    3. **مرحلة الإجابة والخداع (`ANSWERING`):** استقبال الإجابات الحرة، التدقيق الذكي، إبلاغ من أجاب صحيحاً سراً ليصيغ خدعة، واعتماد الإجابة الخاطئة كخدعة مضللة، ومنع تكرار الإجابات المزيفة.
    4. **مرحلة التصويت (`VOTING`):** خلط الإجابة الصحيحة والإجابات المزيفة عشوائياً، حظر تصويت اللاعب على إجابته الخاصة، وجمع الأصوات.
    5. **مرحلة كشف النتائج والنقاط (`ROUND_RESULTS`):** احتساب النقاط (نقطة للصحيحة، ونقطة عن كل لاعب مخدوع)، وكشف أصحاب الإجابات، وتحديث لوحة الصدارة.
    6. **مرحلة نهاية اللعبة (`GAME_OVER`):** تتويج الفائز بعد انتهاء جميع الجولات.
  - إدارة المؤقتات الزمنية المتزامنة بالثواني والبث الحي.
