# طبقة الخدمات (Services)

يحتوي هذا المجلد على الخدمات المسؤولة عن إدارة منطق العمليات المشتركة ومستودع البيانات والغرف.

## الملفات ومحتواها:

- **`topicService.ts`**:
  - خدمة إدارة وتحميل المواضيع والألغاز من ملف `data/topics.json`.
  - التحقق من سلامة وصحة بيانات الألغاز.
  - توفير استعلامات للحصول على ملخصات المواضيع بدون كشف الألغاز.
  - اختيار ألغاز عشوائية لكل موضوع مع ضمان عدم تكرار الألغاز التي لُعبت بالفعل في الغرفة.
- **`roomManager.ts`**:
  - خدمة إدارة دورة حياة الغرف (`RoomManager`).
  - إنشاء الغرف بأكواد فريدة قصيرة.
  - إدارة وحفظ جلسات اللاعبين (`Session Tokens`) للتعامل بسلاسة مع انقطاع الاتصال وإعادة الاتصال السريع دون فقدان المقعد أو النقاط.
  - جدولة تنظيف آلي دوري للغرف الخاملة والمهجورة لتوفير الذاكرة.
