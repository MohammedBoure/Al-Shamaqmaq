# مجلد الوثائق والمهام (Documentation & Tasks)

يحتوي هذا المجلد على خطط التطوير والمهام التفصيلية والتصميمات المرجعية للمشروع.

## الملفات ومحتواها:

- **`tasks.md`**: قائمة بمهام التطوير المطلوبة للواجهة والتصميم والباك إند مع الصور المرجعية.
- **`assets/`**: مجلد الصور ولقطات الشاشة المرجعية لواجهات اللعبة وهوية التصميم (Brawl Stars / Arcade Style).
